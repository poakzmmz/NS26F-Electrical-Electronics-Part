# Datalogger Hardware

KiCad 프로젝트 위치: `imported-source/NS26F-Datalogger-HW/`

- `DLTM.kicad_sch`: 회로도
- `DLTM.kicad_pcb`: PCB
- `DLTM.kicad_pro`: 프로젝트 설정
- `DLTM.pdf`: 회로도 PDF
- `DLTM.step`, `DLTM.SLDASM`: 3D 및 조립 자료
- `production/*_bom.csv`: BOM
- `production/*_positions.csv`: 실장 좌표
- `production/*.zip`: 생산 파일

`DLTM_Old.kicad_pcb`, `DLTM_Old.kicad_pro`, `production/backups/`도 원본 그대로 포함되어 있다.
