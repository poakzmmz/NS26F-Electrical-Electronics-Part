# Datalogger Hardware

KiCad 프로젝트 위치: `imported-source/NS26F-Datalogger-HW/`

- `DLTM.kicad_sch`: 회로도
- `DLTM.kicad_pcb`: PCB
- `DLTM.kicad_pro`: 프로젝트 설정
- `DLTM.pdf`: 브라우저에서 확인 가능한 회로도 PDF
- `production/*_bom.csv`: BOM
- `production/*_positions.csv`: 실장 좌표
- `production/*.zip`: 최종 생산 파일

포트폴리오 공개본에서는 구버전 PCB, 자동 백업, 중간 3D export 등 최종 설계 확인에 불필요한 파일은 제외했습니다.
