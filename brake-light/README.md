# NS26F Brake Light

NS26F 브레이크등 KiCad 프로젝트.

## 구성

- 0805 LED 68개
- 330 Ω 1206 저항 17개
- TVS 다이오드 1개
- SS34 다이오드 1개

## 파일

- `hardware/imported-source/NS26F_BrakeLight/NS26F_BrakeLight.kicad_sch`: 회로도
- `hardware/imported-source/NS26F_BrakeLight/NS26F_BrakeLight.kicad_pcb`: PCB
- `hardware/imported-source/NS26F_BrakeLight/production/`: BOM, 실장 좌표, 생산 ZIP

`production/`에는 초기 버전과 V2 파일이 함께 있다. 두 버전의 BOM 내용은 같다.
