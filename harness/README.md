# Harness

NS26F Formula Student 차량 전장 Harness 관련 공개 문서를 위한 디렉터리입니다.

차량 Harness는 전장 파트에서 직접 설계·제작했으며, ECU·센서·전원·통신 배선을 차량 레이아웃에 맞춰 통합했습니다.

현재 공개 저장소에는 Harness 원본 도면/배선표를 포함하지 않았습니다. 포트폴리오용으로 공개 가능한 범위에서 다음 자료를 추가할 예정입니다.

- 차량 전장 Harness System Overview
- Power / Signal / CAN 배선 구성도
- Connector 및 Branch 구성 예시
- 실제 차량 장착 사진
- 제작 및 검증 과정

> 차량 세부 배선도, 개인/팀 내부 운영정보, 외부 제공 자료 등 공개에 부적절한 정보는 제외합니다.
