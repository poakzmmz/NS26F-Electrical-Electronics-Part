1

종합 주행 분석

속도, 엔진, 기어, 조향과 페달 입력을 한 화면에서 비교합니다.

차량 상태

  • FL·RL·RR 휠 속도 비교
  • 엔진 RPM과 기어 변화 확인
  • 스로틀과 브레이크가 겹치는 구간 확인

조향 그래프

  • Yaw와 횡G 버튼을 눌러 선을 켜거나 끕니다.
  • 핸들 옆 톱니를 눌러 영점·반전·조향 Y축 범위를 설정합니다.
  • 조향 Y축 설정은 표시 범위만 바꾸며 실제 조향각 값은 바꾸지 않습니다.
2

입력 및 서스펜션 분석

운전자 입력과 네 바퀴의 서스펜션 움직임을 비교합니다.

입력 분석

스로틀·브레이크·조향 그래프의 세로 커서는 같은 시점을 나타냅니다. 코너 진입과 탈출에서 입력 순서를 비교할 수 있습니다.

서스펜션 보정

  1. FL·FR·RL·RR 제목 옆 톱니를 누릅니다.
  2. 바퀴별 오프셋을 mm 단위로 입력합니다.
  3. 표시값은 raw × 고정 계수 + 오프셋으로 계산됩니다.

보정값은 이 브라우저에 저장되며 원본 CSV는 변경되지 않습니다.

3

GPS + IMU 주행 분석

실제 주행 위치와 차량 움직임을 같은 시각으로 재생합니다.

재생과 IMU

  • 재생 또는 Space로 시작·정지합니다.
  • 배속은 0.5×, 1×, 2×, 4× 중 선택합니다.
  • IMU LPF는 끄거나 5 Hz·20 Hz 중 선택합니다.
  • X·Y·Z 축 버튼으로 필요한 IMU 선만 표시합니다.

GPS 전체화면

  • GPS 전체화면을 누르면 지도 중심 분석 화면이 열립니다.
  • 상세정보를 켜면 속도·RPM·기어·조향·페달 그래프가 표시됩니다.
  • 재생 중 지도와 상세 그래프 커서는 같은 시점으로 움직입니다.

피니시 라인과 랩 계산

1피니시 라인 설정2지도에서 라인 양 끝 클릭3자동 계산된 LAP 확인4원하는 LAP 선택·비교
  • 라인은 차량 경로가 실제로 통과하도록 트랙 폭을 가로질러 그립니다.
  • 랩을 한 번 누르면 해당 랩만 표시되고, 여러 랩을 누르면 경로와 데이터를 겹쳐 비교합니다.
  • 랩 상세의 시작 지점·종료 지점 버튼은 재생을 멈추고 해당 시점으로 이동합니다.
  • 별표가 붙은 LAP이 베스트 랩입니다.
▶

GoPro·YouTube 영상 동기화

GPS 전체화면에서 영상과 텔레메트리를 함께 재생합니다.

LOCAL MP4

GoPro 원본 파일

  1. CSV를 먼저 엽니다.
  2. GPS 전체화면에서 GoPro MP4를 누릅니다.
  3. 원본 MP4를 선택합니다.
  4. 영상 내부 시작 시각과 CSV 시간이 겹치면 자동 연결됩니다.

파일의 수정일이 아니라 MP4 내부 시작 시각을 사용합니다.

YOUTUBE

YouTube 영상

  1. 영상을 공개 또는 일부 공개로 업로드합니다.
  2. 제목에 촬영 시작 시각을 넣습니다.
  3. GPS 전체화면에서 YouTube를 누르고 링크를 붙여 넣습니다.
  4. 제목과 CSV 시간이 겹치면 자동 연결됩니다.
권장 YouTube 제목NS26F_2026-08-11_15-13-24_KST_GX014229
YOUTUBE UPLOAD HELPER

영상 파일로 제목 자동 만들기

GoPro MP4를 선택하면 영상 내부 시작 시각을 읽어 YouTube 제목과 선택용 설명을 자동 생성합니다. 영상은 업로드되지 않고 이 브라우저에서만 확인합니다.

먼저 원본 MP4 파일을 선택하세요.

제목은 반드시 그대로 사용하세요. 사이트는 제목의 KST 시작 시각으로 CSV와 영상을 맞춥니다. 설명란은 비워도 동기화됩니다.

중요YouTube 영상의 앞부분을 자르거나 인트로를 추가하면 제목의 시작 시각과 실제 영상 0초가 달라져 동기화가 어긋납니다.
4

냉각 및 온도 분석

냉각수·오일·흡기·ECU 온도의 변화와 최고값을 확인합니다.

상단 요약 카드에서 현재 온도와 최고 온도를 확인하고, 아래 그래프에서 시간에 따른 변화와 차량 속도의 관계를 살펴봅니다.

5

실시간 텔레메트리

차량 RF 중계 서버에서 들어오는 데이터를 실시간으로 표시합니다.

실제 연결

  1. 수신 서버 주소를 입력합니다.
  2. 전송 방식을 선택하거나 자동으로 둡니다.
  3. 연결을 누르고 수신률·손실률·RSSI·SNR을 확인합니다.

화면 시험

하드웨어나 중계 서버가 없을 때 데모 모드를 누르면 가상 데이터로 카드와 그래프 동작을 확인할 수 있습니다.

!

문제 해결

자주 발생하는 상황과 확인할 항목입니다.

GPS 지도에 경로가 보이지 않습니다.

CSV에 유효한 위도·경도와 GPS Fix가 포함되어 있는지 확인하고, CSV를 다시 연 뒤 3페이지로 이동합니다.

랩이 계산되지 않습니다.

피니시 라인이 실제 주행 경로를 완전히 가로지르는지 확인하고 최소 랩 시간을 실제 랩타임보다 짧게 설정합니다.

GoPro 또는 YouTube 영상이 연결되지 않습니다.

CSV와 영상의 KST 시간 구간이 일부라도 겹쳐야 합니다. YouTube는 제목 형식과 공개 상태, HD 처리 완료 여부도 확인합니다.

수정된 사이트가 이전 화면으로 보입니다.

브라우저를 새로고침합니다. 계속 같다면 강력 새로고침을 사용하거나 새 탭에서 운영 주소를 다시 엽니다.
